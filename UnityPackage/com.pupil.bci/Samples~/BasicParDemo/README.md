# Basic PAR Demo

1. Create an empty Unity scene.
2. Add an empty GameObject → component **Basic Par Demo Bootstrap** (`Pupil.Bci.Samples`).
3. Start **Gazepoint Control** (TCP 4242).
4. Press Play — after ~2s baseline, near-focus short constrictions increment the counter and flash the bar.

Requires **Unity UI** (`com.unity.ugui`) in the project.
